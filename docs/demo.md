# 本地演示页面

直接运行在有权重和实验结果的服务器上，不依赖云端模型、CDN、Node 或额外 Python Web 框架。界面为中文，模型输入与故事为英文。

服务器：

```bash
conda activate trackglimpse
cd ~/LLM
python main.py stat=web
```

保持服务运行。在你 Windows 电脑另开 PowerShell，执行：

```powershell
ssh -N -L 6006:127.0.0.1:6006 tjw@192.168.50.25
```

该窗口连接后保持开启，然后用电脑浏览器访问 **http://127.0.0.1:6006**。这是把电脑端口转发到服务器，不需要复制权重到本地，也不是在 Windows 电脑训练或推理。

页面包含：

1. 故事实验室：选择基座/SFT/SFT+DPO/SFT+RLVR，输入英文开头，或输入两个英文词进行约束生成。
2. 从零训练：读取 model_info、metrics 和 loss 曲线。
3. Attention：选择精度、batch 和前向/前反向阶段，显示真实图表和测速表。
4. 规模与数据：展示大模型预测/实测误差、清洗统计；若两组 token 相同则明确标注无实际清洗干预。
5. 微调方法：统一测试指标、比较图和真实失败/成功样例。

以上是页面导航，不表示额外实现了第五部分 Agent。底部范围声明第1–4部分、单卡，Agent与多卡实测未包含。

没有结果的地方显示未完成，不填模拟指标；模型文件缺失时不能选择。页面按需只缓存一份模型，切换模型时释放前一份。约束生成受模型上下文长度限制，实际生成上限可能低于输入值；续写模式沿用滑动上下文。复制按钮复制当前文本。

默认绑定 127.0.0.1，通过 SSH 转发访问。本程序是课程本地 demo，没有公网账户认证，不提供任意文件读取或运行 shell 的接口。Ctrl+C 关闭服务；不要与正式 GPU 训练同时运行大批生成。

配置在 configs/web/default.yaml：training_dir、attention_dir、science_dir；微调目录和基座路径沿用 alignment 配置。默认自动读取本项目已有 artifacts 目录。换端口时服务和 SSH 两端都改为同一个新端口。

## 建议演示顺序（约 3 分钟）

- 先展示训练曲线和参数量，说明从零实现的模块。
- 输入同一故事开头，展示真实续写和模型局限。
- 看 Attention 的前向+反向图，区分算子加速和完整模型训练。
- 看外推误差和清洗的零变化对照，如实解释数据已较干净。
- 在第四部分比较模型对相同词语要求的输出，展示统一测试结果及失败样例。

浏览器本地预览检查了桌面布局及空结果状态，HTTP 测试覆盖静态资源、结果接口、生成请求及非法路径。正式模型生成与实验展示需服务器现有文件和训练结果；Windows 本地未执行 0.1B GPU 微调。
